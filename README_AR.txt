aPHRi Academy — النسخة الأولى
============================
المحتويات:
- index.html: التطبيق
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت
- sw.js: دعم العمل دون اتصال بعد أول تحميل
- icon.svg: أيقونة التطبيق

طريقة النشر والتثبيت:
1) ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify).
2) افتح رابط الموقع من Chrome على Android أو Safari على iPhone.
3) Android: قائمة المتصفح > Install app أو Add to Home screen.
4) iPhone: زر المشاركة > Add to Home Screen.

ملاحظات:
- لا يعمل تثبيت PWA من ملف محلي مباشرة؛ يلزم نشره على HTTPS.
- تقدم الدراسة محفوظ محلياً على الجهاز والمتصفح باستخدام localStorage.
- النسخة الحالية تتضمن الدرس 1.1 وأربعة أسئلة تدريبية ومحاكاة مصغرة من 4 أسئلة / 8 دقائق.
- هذه ليست محاكاة كاملة لامتحان HRCI، ولا تحتوي على أسئلة مسربة أو أسئلة فعلية سرية.
- المحتوى الدراسي الأولي مستند إلى ملف AREA 01 الذي رفعه المستخدم، Section 1.1.
